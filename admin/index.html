First-time setup

Create a restricted GitHub token

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Limit repository access to MythicSuite only.
  3. Set repository permission Contents to Read and write.
  4. Give the token an expiry date, then paste it above whenever you edit the site.

Do not put the token into source code, plugins.json, Discord, or a public screenshot.
