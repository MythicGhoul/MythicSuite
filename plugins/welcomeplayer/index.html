Full overview

Reward players for welcoming newcomers and support simple referral bonuses.

WelcomePlayer is designed to encourage social interaction at the exact moment it matters most: when someone joins the server and needs acknowledgement from the community.

Instead of treating a warm welcome as something purely cosmetic, the plugin turns it into a small reward loop with configurable messages, time windows and optional referral bonuses for invited players.

Best suited toCommunity-focused servers that want onboarding and social engagement to feel meaningful.

How it works

Detect genuine welcomes, reward greeters and handle referrals

When a player joins, the plugin opens a short welcome window. If another player sends a configured welcome phrase within that period, the greeter is rewarded according to whether the joining player is new or returning.

The referral system optionally lets new players run /referral <player> to credit the friend who brought them in, with configurable command rewards for both the referrer and the newcomer.

  • Makes chat feel friendlier
  • Rewards positive social behaviour
  • Includes a built-in referral flow
  • Simple to adapt through config commands

Key features

What this plugin focuses on

  • Greeter rewards for welcome messages — Players receive rewards when they properly greet a joining player within the allowed time window.
  • Separate first-time and returning-player rewards — Different command rewards can be used depending on whether the joining player is brand new or simply coming back.
  • Referral reward system — New players can credit the person who invited them and trigger additional rewards.
  • Configurable time window and cooldowns — Prevent spam and control how long welcome opportunities remain open.
  • Custom trigger word lists — Define exactly which welcome phrases count for first-time and returning players.
  • Simple admin reload support — Staff can refresh configuration changes without a full restart.

Reward commands, message text, welcome phrases and referral rules all live in config.yml, making it easy to align the system with the server economy and onboarding goals.

Setup guide

Recommended starting checklist

  • Install the plugin and configure reward commands in config.yml.
  • Set the welcome time window, cooldowns and valid greeting phrases.
  • Enable or disable referrals depending on your onboarding flow.
  • Use /wp reload after editing.
