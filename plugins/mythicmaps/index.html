Full overview

Image maps, GIF maps, floating displays and transparent sprite art for Minecraft worlds.

MythicMaps is built for servers that want to bring custom art into the world in more than one form. It supports traditional image maps, animated GIF playback and modern display-based presentation.

The plugin is designed as a media toolkit rather than a single-purpose image importer, making it useful for spawn art, billboards, quests, decorations and interactive builds.

Best suited toCreative hubs, RPG servers and showcase worlds that want custom media embedded into the environment.

How it works

Import media, choose the presentation style and deploy it in-world

Images are stored inside the configured images folder, then converted into one or more maps or display records. The plugin supports fit modes, wall limits, scale values and saved records for later reuse.

Animated GIFs use dedicated renderers and timing controls, while display and sprite systems allow more modern presentation styles with transparency handling and performance boundaries.

  • Supports both classic maps and modern displays
  • Useful for art, signage and animated showcases
  • Multiple fit and scaling options
  • Persists map and display data

Key features

What this plugin focuses on

  • Static image maps — Convert still images into map art for walls, framed displays or decorative builds.
  • Animated GIF map rendering — Play moving media through optimized GIF renderers with timing controls.
  • Floating display entities — Use display entities for clean presentation without relying only on item frames.
  • Transparent sprite displays — Render sprite-style visuals with alpha threshold handling for cleaner cut-outs.
  • Fit modes and scaling controls — Choose how images fill their target area and how large they appear.
  • Saved map and display data — Persist records so media installations can survive restarts and be managed later.

Maximum wall size, GIF behaviour, sprite scaling and entity caps are all configurable so the system can be adapted to different hardware and build styles.

Setup guide

Recommended starting checklist

  • Create or copy media files into the configured images folder.
  • Configure fit mode, wall limits, GIF options and display defaults.
  • Use /mythicmaps (or /mmap) commands to create and manage displays.
  • Test animated media carefully in your target world.
