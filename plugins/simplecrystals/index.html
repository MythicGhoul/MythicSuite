Full overview

Right-click crystals for healing, hunger, money, XP, travel, weather and playful trick effects.

SimpleCrystals adds a set of right-click consumables that turn familiar materials into one-use server utilities. Each crystal is identified by its configured material and display name, then consumed when its effect succeeds.

The supplied source includes healing, food, money, EXP, spawn, day and weather crystals alongside two deliberately misleading prank crystals. An administrative GUI can distribute the items without requiring staff to remember every subcommand.

Best suited toLegacy survival or economy servers that want simple one-use utility rewards with a fantasy crystal theme.

How it works

Give a crystal, right-click it and consume its configured effect

Staff create crystals through /sc subcommands or the admin menu. Players with the matching permission right-click the named item in their main hand to activate it.

The plugin validates the configured material, display name and permission before applying the effect. Healing uses a configurable cooldown, money is deposited through Vault, and successful consumables are removed from the held stack.

  • Nine distinct utility and prank consumables
  • Configurable materials and player-facing messages
  • Vault-backed money rewards
  • GUI and command-based administration

Key features

What the supplied source implements

  • Nine consumable crystal types — Healing, Food, Money, EXP, Spawn, Day, Sun, God/Trick and Op/Trick items are present in the source.
  • Full heal and hunger restoration — Healing and Food crystals restore the player to maximum health or food when needed.
  • Money and experience rewards — Money crystals deposit the configured Vault amount, while EXP crystals grant a fixed experience reward.
  • Spawn, daytime and clear-weather crystals — Utility crystals execute spawn, time and weather commands and consume the item.
  • Admin crystal GUI — The GUI presents the crystal catalogue and lets permitted staff distribute each item.
  • Configurable materials, values and messages — Crystal materials, cooldown, money amount and feedback messages are stored in config.yml.

SimpleCrystals is a legacy project and should be tested against the target server version. Vault and a registered economy provider are required at startup. The Spawn, Day and Sun crystals execute server commands through the player, so the relevant command provider and permissions must exist.

Setup guide

Recommended starting checklist

  • Install Vault and a compatible economy provider before starting the server.
  • Review every CrystalTypes material and the MoneyCrystal value in config.yml.
  • Ensure the server provides working /spawn, /time and /weather commands for the related crystals.
  • Grant only the sc.* crystal permissions intended for each player group.
