Full overview

Fast crop harvesting with sensible inventory-based replanting.

EasyReplant streamlines crop harvesting while keeping seed and crop resources meaningful. Supported plants are replanted only when the player actually carries the required item, avoiding free infinite replanting.

Optional growth and multi-harvest mechanics can make farming more rewarding without replacing the basic survival loop.

Best suited toSurvival servers that want faster farming without turning crops into a free automated resource.

How it works

Harvest quickly while preserving inventory costs

When a supported mature crop is harvested, the plugin checks the player inventory for the correct replanting item. A valid item is consumed and the crop is restored at its starting age.

Additional settings can influence growth, harvest bonuses and special handling for plants such as sugar cane and cactus.

  • Reduces repetitive planting clicks
  • Consumes real seeds or crops from inventory
  • Supports configurable farming bonuses
  • Keeps the mechanic lightweight and easy to learn

Administration

Configuration and live-server use

Server owners control supported crops, growth behaviour and bonus chances. Because this is a legacy resource, modern server versions should be tested carefully for block-event and crop-age behaviour.
