Full overview

Purchasable join and leave messages with real player identity.

MythicJoins turns ordinary login and logout text into a cosmetic collection system. Players can browse themed join and leave messages, purchase them through a Vault economy and select the style that represents them.

The plugin keeps cosmetics separate from gameplay power. A player can build a collection, switch between owned messages and still fall back to a polished default pool when no custom option is selected.

Best suited toCommunity servers that want a visible cosmetic economy without selling gameplay power.

How it works

A complete cosmetic shop for arrivals and departures

The shop presents available join and leave messages with icons, prices and formatting. Purchased entries move into an owned-items menu where players choose their active message independently for joining and leaving.

Server staff can grant, revoke and manage cosmetics without editing player files. Optional Discord webhooks mirror the chosen message with the player's identity, creating a consistent experience between Minecraft and the community server.

  • Economy sink with no competitive advantage
  • Separate shops and owned-message menus
  • Configurable defaults for players without a selection
  • Discord embeds using the player identity and selected message

Administration

Configuration and live-server use

Messages, prices, icons, colours and categories are configuration-driven. This makes the resource suitable for small cosmetic catalogues or a large rarity-based collection without requiring code changes for every new message.
