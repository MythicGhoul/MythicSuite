# MythicSuite Vibrant Preview

This is a visual preview build of the redesigned MythicSuite homepage.

Included in the preview:
- Abstract animated hero
- Purple, neon cyan and restrained gold visual system
- Orbital plugin artwork
- Premium statistics ribbon
- Large LevelCraft flagship feature
- Bento-style plugin portfolio
- Release Radar activity feed
- Upgraded call-to-action and footer
- Responsive mobile layout
- Reduced-motion accessibility support

The existing Resources, Statistics, About and detailed plugin pages are retained.


## Transparent plugin logos

All active PNG plugin artwork has had its outer black, white, or checkerboard
square removed. The images are now transparent PNGs, cropped and rescaled to a
consistent visual size. Website image CSS no longer adds a square background
or border behind the logos.


## Supplied plugin logo pack

The website now uses the supplied transparent badge artwork for 25 plugins. The existing LevelRewards badge remains because it was not included in the uploaded logo pack. All images were normalised to transparent 640×640 PNG assets for consistent display and page weight.
