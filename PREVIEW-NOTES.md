# MythicSuite Vibrant Preview

This is a visual preview build of the redesigned MythicSuite homepage.

Included in the preview:
- Abstract animated hero
- Purple, neon cyan and restrained gold visual system
- Orbital plugin artwork
- Premium statistics ribbon
- Large LevelCraft flagship feature
- Bento-style plugin portfolio
- Release Radar activity feed
- Upgraded call-to-action and footer
- Responsive mobile layout
- Reduced-motion accessibility support

The existing Resources, Statistics, About and detailed plugin pages are retained.
