# MythicSuite live tracker build

This build adds:

- A live total site-page-view badge beneath the navigation on every page
- A separate live page-view badge on every plugin page
- Anonymous click tracking for internal navigation, platform links and downloads
- Aggregate click statistics and per-plugin click buckets
- Cache-busted CSS and JavaScript filenames

The counters use Hits.sh. They count page requests rather than unique people.
No cookies, IP profiles or fingerprinting are added by the website code.

Statistics links:

- Site views: https://hits.sh/mythicsuite.co.uk/site/
- All clicks: https://hits.sh/mythicsuite.co.uk/clicks/all/
- Plugin views: https://hits.sh/mythicsuite.co.uk/plugins/PLUGIN-ID/
